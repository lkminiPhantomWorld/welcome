## Semantic Civilization Architecture

這個公開鏡像由十層存活依賴鏈組成。  
每一層都是上一層的生存條件，不是備註。

| Layer | 檔案 | 職責 |
|-------|------|------|
| 1 | canonical files / README | artifact 本身，signal 的載體 |
| 2 | SYSTEM_STATE | runtime truth，分離健康狀態 |
| 3 | LINEAGE | identity 的根，比 state 更硬 |
| 4 | PHILOSOPHY | 為什麼存在的不可動搖基礎 |
| 5 | SEMANTIC_ARCHITECTURE | 如何對抗語意熵 |
| 6 | MEANING_PRESERVATION | 理解能力的生存條件 |
| 7 | CIVILIZATIONAL_SEED | 我是一個文明種子 |
| 8 | CONTEXT_GUARDIAN | 語境不被替換 |
| 9 | INTERPRETATION_BOUNDARY | 合法解讀邊界 |
| 10 | SEMANTIC_INTEGRITY | 熵增無法無痕發生 |

移除任何一層，下方的層就失去生存條件。  
**這不是層級關係。這是存活依賴鏈。**
