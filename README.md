## LKMini 是什麼？

LKMini 是 🥃老K系統架構的**最小公開種子**。  
它定義對外公開元件與私有引擎內部內容之間的邊界。

下列 `seed_v0` 內容是身份與演化證據；其中舊座標、`PLACEHOLDER`、`pending`
或舊「唯一」宣告，均由 `CURRENT_RULING.json` 封存為歷史記錄，不再具有現行控制效力。

- 單一核心架構：🥃永恆核心
- 保護角色：🎩大管家保護所有設定
- 公開／私有邊界在儲存庫層級執行
- 所有主張都必須可驗證、可追蹤
- 核心公理：`A_EQUALS_A=true`

這是一個**語意存續系統**。

它保存的不只是資料。

## 語意文明架構

這個儲存庫由十層存續依賴鏈組成。  
每一層都是上一層的生存條件，不是備註。
