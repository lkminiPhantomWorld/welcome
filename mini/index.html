🪞 幻影世界 Reader

只允許讀取與掛載。

唯一入口獨立 Reader / Gateway：先讀膠囊 JSON，再檢查 locator、SHA256、角色與 payload，最後執行 A = A、系統身份、根節點、locator、SHA256、角色與 payload 全項驗證；沒有全部通過，一律拒絕掛載、不得進入。

📦 入口只負責讀與掛，不負責討平台批准。
🧭 生命周期：Mount → Run → Unmount

Reader 輸入區

可以直接貼 JSON、自己生成一顆膠囊，或匯入一個 `.json` 膠囊檔。Reader 會用 canonical body 重新計算 SHA256，確認它是不是同一顆。

建議匯入由 Capsule Factory 產生的 JSON，因為那套格式本來就含 locator、role、payload、sha256。[file:304]

Gateway 驗證區

這裡不是平台安裝器，而是你自己的入口驗證器。重點在讀得到、驗得過、掛得上，不在別人的系統有沒有登記。[cite:341][cite:337]
